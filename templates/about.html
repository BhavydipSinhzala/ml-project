Project Overview & Architecture

Technical specification, dataset breakdown, and machine learning pipeline implementation details.

Project Objective

The FinRisk AI system estimates loan default probability using a trained Gradient Boosting Classifier. The system evaluates applicant financial health, employment background, credit lines, and requested loan terms to predict whether an applicant is likely to default (Target variable Default: 0 = No Default, 1 = Default).

Dataset Specifications

Total Dataset Records255,347 loan applications
Target VariableDefault (0 = No Default, 1 = Default)
Class Distribution~88.4% Non-Default, ~11.6% Default (Imbalanced Dataset)
Source FileLoan_default.csv
Feature Count17 total attributes (9 Numeric, 4 Categorical, 3 Binary, 1 ID)

Feature Schema

Numerical & Financial Features

  • Age
  • Annual Income ($)
  • Requested Loan Amount ($)
  • Credit Score
  • Months Employed
  • Number of Credit Lines
  • Interest Rate (%)
  • Loan Term (Months)
  • Debt-to-Income (DTI) Ratio

Categorical & Binary Indicators

  • Education Level
  • Employment Type
  • Marital Status
  • Loan Purpose
  • Has Mortgage Indicator
  • Has Dependents Indicator
  • Has Co-Signer Indicator

Preprocessing & Pipeline

  1. Deduplication: Removal of duplicate records across the dataset.
  2. One-Hot Encoding: Conversion of categorical columns (Education, Employment, Purpose, Marital Status) into binary dummy features.
  3. Binary Mapping: Standardizing boolean toggles (HasMortgage, HasDependents, HasCoSigner).
  4. StandardScaler Normalization: Feature scaling applied to numerical inputs for balanced model convergence.
  5. Train/Test Partitioning: 80/20 stratified split (`random_state=42`).
